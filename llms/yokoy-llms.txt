# Yokoy API

> Yokoy (now part of Perk / TravelPerk) is an AI-powered spend-management platform. Its public REST API (OpenAPI 3.0) imports master and configuration data into Yokoy and exports financial data — expenses, trips, invoices, transactions, journal entries and FX rates — to third-party finance systems. Authentication is OAuth2 client-credentials; all requests are scoped to an organization ID and usually a legal entity (company) ID.

## Environments
- Production: https://api.yokoy.ai/v1/organizations/{organizationId}
- Test: https://api.test.yokoy.ai/v1/organizations/{organizationId}

## Conventions
- Auth: OAuth2 client-credentials (no scopes); pass bearer token.
- Pagination: cursor-based (`cursor` + `count` query params).
- Filtering: `filter` query param on list endpoints.
- Tracing: optional `X-Yk-Correlation-Id` request header.
- Errors: JSON `{ code, message }` envelope; validation errors add `field`.
